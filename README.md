# PCAP Analysis Lab

This repository documents my hands-on practice analyzing packet captures with Wireshark. Through these investigations, I explore network traffic, identify suspicious activity, and build my packet-analysis skills.

Each PCAP investigation has its own branch and includes:

- Background information and investigation objectives.
- A step-by-step account of my thought process, including questions, observations, and decisions.
- Wireshark filters and techniques used during the analysis.
- Screenshots supporting my findings.
- Final answers, supporting evidence, and lessons learned.

The goal is to show how I reached each conclusion, including unsuccessful searches and how they shaped my next steps.

Analyses use publicly available training captures, with links and attribution to their original sources.
